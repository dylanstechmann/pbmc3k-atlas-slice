# Methods

Generated by `pbmc3k-atlas-slice` on 2026-09-27T01:12:52+00:00.

- Dataset: 10x Genomics PBMC3k (`https://cf.10xgenomics.com/samples/cell-exp/1.1.0/pbmc3k/pbmc3k_filtered_gene_bc_matrices.tar.gz`), sha256 `847d6ebd9a1ec9a768f2be7e40ca42cbfe75ebeb6d76a4c24167041699dc28b5`.
- Software: scanpy 1.12.4, anndata 0.13.4, numpy 2.5.3.
- QC: 200-2500 genes/cell, mito fraction <= 0.05, genes in >= 3 cells.
- Normalization: per-cell totals to 1e4, log1p; top-2,000 HVGs; scaled to max 10; 40-component PCA; 10-NN graph; Leiden (resolution 1.0, seed 0).
- Cell types: rule-based assignment by maximum mean scaled expression of canonical marker pairs (see scripts/analyze.py MARKER_SETS).
- Module scores: `sc.tl.score_genes` over the genes present in the data (present/missing lists in data/provenance receipts).

**Interpretation limits:** PBMC3k is a healthy-donor reference with no
senescence induction; module-score variation across cell types is shown as a
method demonstration and does not identify senescent cells.
